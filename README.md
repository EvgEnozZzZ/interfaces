# FleetDispatch

Простая информационная система диспетчеризации и учета автопарка для логистики на Qt C++ с использованием SQLite.

## Функционал

- Учет транспортных средств
- Учет водителей
- Планирование и контроль рейсов
- Отслеживание статусов автомобилей и водителей
- Просмотр базовой статистики по автопарку
- Хранение данных в SQLite

## Требования

- Qt 6.x или Qt 5.x
- Компилятор C++
- qmake

## Сборка

1. Установите Qt Creator и Qt.
2. Откройте файл `FleetDispatch.pro`.
3. Соберите проект через Qt Creator или командой:

```bash
qmake FleetDispatch.pro
make
```

Для Windows с MinGW:

```bash
qmake FleetDispatch.pro
mingw32-make
```

## Запуск

После сборки запустите исполняемый файл `FleetDispatch`.

## Структура данных

База данных создается автоматически и хранится в файле `fleet_dispatch.db` в рабочей директории приложения.

## Основные таблицы

- `vehicles`
- `drivers`
- `trips`

## Автор

Учебный проект для демонстрации Qt + C++ + SQLite.
